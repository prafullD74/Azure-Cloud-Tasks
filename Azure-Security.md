## [Azure security capabilities](https://go.microsoft.com/fwlink/?linkid=2313766&clcid=0x4009)
1. [Azure Key Vault](https://azure.microsoft.com/en-in/products/key-vault/): Safeguard cryptographic keys and other secrets used by cloud apps and services.
2. [Azure DDoS Protection](https://azure.microsoft.com/en-in/products/ddos-protection/): Protect your Azure resources and prevent **distributed denial-of-service** (DDoS) attacks.
3. [Azure Firewall](https://azure.microsoft.com/en-in/products/azure-firewall/): Help enhance protection with real-time threat alerts, a scalable firewall, TLS inspection, and centralized security management.
4. [Azure confidential computing](https://azure.microsoft.com/en-in/solutions/confidential-compute/): Access a wide range of confidential compute options, including hardware, services, tools, and SDKs to protect your data.
5. [Microsoft Defender for Cloud](https://azure.microsoft.com/en-in/products/defender-for-cloud/): Protect multicloud and hybrid environments with comprehensive security from code to cloud.
6. [Azure Integrated HSM](https://go.microsoft.com/fwlink/?linkid=2313650&clcid=0x4009): The in-house security chip inside every new Azure server strengthens key protection by default, meeting demanding FIPS 140-3 security requirements.
